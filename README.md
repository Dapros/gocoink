# GoCoink Mobile App

GoCoink es la aplicación móvil desarrollada en **React Native** utilizando **Expo** y **Expo Router**, diseñada para ofrecer una experiencia rápida, fluida y moderna.

---

## Stack

* **Framework:** React Native con Expo
* **Enrutamiento:** Expo Router
* **Gestor de Paquetes:** Bun sh
* **Estilos:** Tailwind CSS / NativeWind (o estilos nativos)
* **Manejo de Estado:** Zustand
* **Base de Datos:** SQLite (version de Expo)
